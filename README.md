# 武史藏经阁

一个面向小说创作的中文可视化知识库阅读器。它把“武侠 × 历史深度蒸馏”的结构化成果整理为可检索、可追溯、可比较的阅读界面，帮助创作者从叙事机制、章末承诺、人物关系与史料边界中提取可复用的方法。

网站只展示蒸馏后的摘要、标签、统计与证据定位，不收录原电子书全文或长篇摘录。

## 主要功能

- 综合蒸馏：从核心洞见直接跳转到对应来源与分段证据。
- 创作控制台：按叙事节奏、冲突、人物、信息释放等控制项查看可执行建议。
- 来源浏览：查看每部作品的概览、章节地图、连续性台账与相邻来源关系。
- 维度分析：以九个写作维度横向比较不同来源中的叙事手法。
- 分段卡：查看结构化卡片、叙事模式、章末承诺、参与者标签和证据定位。
- 全局搜索和筛选：支持作品、作者、标签、类型与来源类别检索；键盘可用快捷键 Ctrl + K 或 Command + K 聚焦搜索。

为了保持 2,026 张卡片下的浏览性能，前端使用预构建的静态索引与按来源分片的数据文件；页面只在需要时读取对应数据，而不把所有 Markdown 原文堆入 DOM。

## 数据与使用边界

- 历史材料中的事实、人物、年代与因果关系应以独立史料核验；站内的写作归纳不替代事实判断。
- 对历史材料所作的叙事化概括属于创作重构，不等同于史实陈述。
- 分段卡中的参与者识别含有启发式推断，置信度为低至中等时不得作为确定结论使用。
- 证据定位用于回到蒸馏成果中的来源、章节或分段位置；它不是原文转载。
- 本项目用于学习、研究与原创创作辅助。使用者应遵守作品版权与合理使用边界。

作品之间只展示有明确依据的连接：明朝史料七册的卷次关系、射雕—神雕—倚天的代际关系，以及《飞狐外传》与《雪山飞狐》的连续性。其余来源保持独立，避免制造未经证实的关联。

## 本地启动

需要 Node.js 22.13 或更高版本。

~~~bash
npm install
npm run dev
~~~

默认通过 Vinext 启动本地开发服务器，固定访问地址为 http://127.0.0.1:44000。

Windows 用户也可以双击桌面的“启动武史藏经阁”快捷方式。首次使用前请先完成一次 npm install；启动后保持弹出的终端窗口开启，关闭窗口即停止本地服务。

生产构建与检查：

~~~bash
npm run lint
npm run build
~~~

## 更新蒸馏数据

原始蒸馏成果不纳入本仓库。将目录位置通过环境变量 WUXIA_LIBRARY_ROOT 指向本机的结构化蒸馏输出，再运行数据构建脚本：

~~~powershell
$env:WUXIA_LIBRARY_ROOT = 'D:\path\to\wuxia-history-deep-craft-library'
npm run build:data
~~~

数据构建会读取每书的 overview、chapter-map、continuity-ledger，以及 sources、synthesis、craft-controls、quality-report 等结构化文件，并生成浏览器使用的静态数据：

~~~text
public/data/catalog.json
public/data/search.json
public/data/sources/<source-id>.json
~~~

更新数据后，运行 npm run lint 与 npm run build，再检查来源数、卡片数、维度数和页面中的跳转是否符合预期。
